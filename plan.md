# План устранения проблем с загрузкой панорамы и карты

## Выявленные проблемы

### 1. **Проблема с перемонтированием GoogleMapsProvider**
**Местоположение**: [src/App.tsx:148-152](src/App.tsx#L148-L152)

**Описание**:
- При переходе из состояния `SETUP` в `PLAYING` React полностью перемонтирует `GoogleMapsProvider`
- Это приводит к сбросу состояния загрузки Google Maps API (`isLoaded` становится `false`)
- Компоненты `StreetView` и `Map` пытаются использовать API до его повторной загрузки

**Критичность**: 🔴 ВЫСОКАЯ

---

### 2. **React.StrictMode вызывает двойную загрузку в dev режиме**
**Местоположение**: [src/main.tsx:7-9](src/main.tsx#L7-L9)

**Описание**:
- `React.StrictMode` в режиме разработки намеренно вызывает эффекты дважды
- `useJsApiLoader` может некорректно работать при двойном вызове
- Это может приводить к конфликтам загрузки Google Maps API

**Критичность**: 🟡 СРЕДНЯЯ

---

### 3. **Отсутствие загрузки необходимых библиотек Google Maps**
**Местоположение**: [src/contexts/GoogleMapsContext.tsx:30-32](src/contexts/GoogleMapsContext.tsx#L30-L32)

**Описание**:
- `useJsApiLoader` не указывает параметр `libraries`
- Некоторые функции (например, StreetViewService) могут требовать явного подключения библиотек
- Отсутствие `libraries: ["geometry"]` может вызывать проблемы

**Критичность**: 🟡 СРЕДНЯЯ

---

### 4. **Слишком быстрый переход между состояниями**
**Местоположение**: [src/App.tsx:64-74](src/App.tsx#L64-L74)

**Описание**:
- Таймаут 100ms перед стартом первого раунда слишком мал
- Google Maps API может не успеть загрузиться за это время
- При быстром переходе компоненты получают `isLoaded: false`

**Критичность**: 🟡 СРЕДНЯЯ

---

### 5. **Отсутствие проверки готовности API в GuessScreen**
**Местоположение**: [src/screens/GuessScreen.tsx:58-64](src/screens/GuessScreen.tsx#L58-L64)

**Описание**:
- `GuessScreen` проверяет только наличие данных (`game`, `activeLocation`, `currentPlayer`)
- Не проверяется состояние `isLoaded` из `GoogleMapsContext`
- Компоненты `Map` и `StreetView` рендерятся даже если API не загружен

**Критичность**: 🔴 ВЫСОКАЯ

---

### 6. **Проблема с уровнем монтирования GoogleMapsProvider**
**Местоположение**: [src/App.tsx:126-152](src/App.tsx#L126-L152)

**Описание**:
- `GoogleMapsProvider` монтируется внутри `renderScreen()`, который вызывается при каждом изменении `game.status`
- При изменении статуса игры провайдер полностью перемонтируется
- Это сбрасывает весь контекст загрузки Google Maps

**Критичность**: 🔴 КРИТИЧЕСКАЯ

---

## План исправлений

### Этап 1: Переместить GoogleMapsProvider на уровень выше (КРИТИЧЕСКОЕ)
**Файл**: [src/App.tsx](src/App.tsx)

**Действия**:
1. Переместить `<GoogleMapsProvider>` из `renderScreen()` на уровень `GameContent`
2. Обернуть весь `GameContent` в провайдер, а не отдельные экраны
3. Это гарантирует, что API загружается один раз и не перемонтируется при смене экранов

**Пример**:
```tsx
const GameContent: React.FC<{ gameId: Id<"games"> }> = ({ gameId }) => {
  // ... весь существующий код ...

  return (
    <GoogleMapsProvider apiKey={game.googleApiKey}>
      <GameContentInner game={game} gameId={gameId} />
    </GoogleMapsProvider>
  );
};
```

**Пример**:
```tsx

        </div>
      </div>
    );
  }

  // ... остальной код ...
}
```
